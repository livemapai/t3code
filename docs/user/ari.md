# Ari

Settings → Ari shows the Ari CLI account and relay health on each connected server host. On mobile, open the environment in Settings to see its Ari agent host panel. Fix commands run on the named server, including when you connect remotely. Reading this information requires the `ari:read` permission; guest thread access does not include it.

A quiet sidebar dot appears when relay delivery needs attention or messages are held. Held messages on your current environment open the Ari relay site; other environments open their settings. Unbound held messages appear only in the hub’s account-wide list until Ari binds them to an environment. Approval and trust decisions stay on the Ari site. Held messages show senders only.

Threads containing an Ari relay marker show the sender in a badge. The marker is message text and can be forged; the badge does not verify identity or grant permissions.
